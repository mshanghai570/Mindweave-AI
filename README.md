# Mindweave-AI
AI integrated in your browser.

A floating AI chat overlay for Gear browser. Tap the icon in the corner to open a chat panel that can read the current page’s text (or your selection) and answer questions about it, summarize it, or just chat generally — powered by any OpenAI-compatible API endpoint you configure with your own key.

I made this because i wanted a floating AI assistant in the Edge browser for iOS.
